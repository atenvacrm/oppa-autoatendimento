# Continuidade do projeto Oppa

Repositório: atenvacrm/oppa-autoatendimento. Branch principal: main.

Este é o sistema de autoatendimento Oppa, independente do site comercial Totemlab e do Atenva CRM.

Mantenha a identidade já aplicada e preserve os fluxos de pedido demonstrativo. O projeto é estático, com HTML, CSS e JavaScript sem compilação. As fotografias e fontes estão em assets. Faça commits para preservar as alterações entre chats. Verifique o deploy da hospedagem conectada após cada push.
